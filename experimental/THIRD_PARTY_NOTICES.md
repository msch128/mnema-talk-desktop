# Experimental desktop third-party notices

This development source checkpoint uses the pinned dependencies in app/Cargo.lock and the canonical ../mnema-talk/web/package-lock.json. The full original package license and notice texts are in licenses/texts/; licenses/manifest.json maps package/version/checksum to those texts. The graph includes optional and build dependencies conservatively and does not claim measured linking.

OpenMLS source is based on commit 3a3e35de3feeca8f6605143c464d5452ae584d43 under its original MIT license. Mnema updates the HPKE dependencies in its RustCrypto and libcrux provider manifests from 0.7 to 0.8 to remove the vulnerable libcrux-kem 0.0.9 pin (RUSTSEC-2026-0330 and RUSTSEC-2026-0331), and updates the libcrux provider's HMAC-DRBG dependency to 0.0.2 (RUSTSEC-2026-0329). The retained workspace locks also include h2 and rustls security updates. These are local modifications to the pinned source, recorded with original and current hashes in [source-provenance.json](source-provenance.json). SFrame source is pinned to commit c11d7f452c6c947ed5ea6a13c35ce600ba1584e2 under its original MIT/Apache-2.0 choices. Both complete source workspaces and original notices are retained in vendor/. The complete Rust 1.99.0 standard-library copyright notice, Inter OFL attribution, and build CSS notices are retained in licenses/.

GLib 0.18.5 retains its upstream MIT license and version. [vendor/glib/](vendor/glib/) includes the two-line [upstream iterator fix](https://github.com/gtk-rs/gtk-rs-core/commit/b5a4071e439bef2b5eea76c3aa25e5ae84839e34) for RUSTSEC-2024-0429. [vendor/glib-source.json](vendor/glib-source.json) records the original archive checksum and all source file hashes. The mandatory source check and license collector verify the exact backport and include its original license text.

`keyring` 3.6.3 (MIT OR Apache-2.0) stores the session cookie in the macOS Keychain or Windows Credential Manager, with its macOS and Windows platform dependencies; they are in the locked inventory and licenses/manifest.json.

SQLCipher/OpenSSL source packages and their original notices are included in the locked registry inventory. `tauri-plugin-updater` 2.14.0 (Apache-2.0 OR MIT) and `minisign-verify` 0.3.0 (MIT) update the installed client: the installer is run only after its minisign signature verifies against the public key built into the app. The plugin's archive dependencies (`tar`, `zip`, `flate2`) are in the locked inventory and licenses/manifest.json. The private updater key is not in this repository. No code-signing certificate is configured; the installer is not Authenticode-signed.

The copied existing web DeepFilterNet WASM/model has an additional provenance and transitive-license qualification gap. Its existing notices are preserved; this checkpoint makes no claim that a final binary distribution license closure is complete.

See the project root THIRD_PARTY_NOTICES.md for existing web/backend dependencies and LICENSE for project terms.
